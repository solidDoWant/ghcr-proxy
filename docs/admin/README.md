# ghcr-proxy for admins

For: people who install ghcr-proxy and set up CI pods to use it. You know Kubernetes, Helm, Flux, cert-manager and Tekton.

ghcr-proxy is in early development. The pages for admins are not written yet. They will describe how to install the chart, give the proxy the PAT and the TLS certificate, set the grants for each namespace, and set up a CI pod. They will also describe the security limits and how to fix problems.

- [Chart values](chart-values.md): every Helm value (generated).

[`SPEC.md`](../../SPEC.md) has the full rules.
